几何（对照提案 §3.2）
  • 宠物先下潜、窗口后变大：卡片 112 高 < 宠物 120，反序会露出头顶 8px。
  • 同一锚点：宠物被拖到哪，卡片就从它的右下角向左上长出，所以永远盖得住。
  • 单击宠物 = 聚焦主窗（原型只打印一行提示）。悬停卡片会暂停自动消失。
  • 透明窗口、置顶、不抢焦点、拖拽持久化只能在 Tauri 侧验证（提案 P0 清单）。
