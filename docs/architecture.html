分层架构

九个层次，每一层只依赖它下面的那一层。想读懂这个项目，先看三个文件： lib.rs（状态与命令）、 llm_complete.rs（对话主循环）、 agents.rs（派活与汇总）。

  • 核心入口（先读这几个）
  • 项目内模块
  • 外部依赖
  • 主链路 / 循环
02

一次对话轮

一轮 = 多次上游请求。工具结果必须紧邻它的 assistant(tool_calls)， 所以 mid-turn 插话只在「轮首」这个唯一安全边界注入，上下文压缩也只在这里做。

03

子智能体编排

规划器把一条请求拆成若干 Task，交给三类后端并行执行；交付物走 .data/tmp 而不是塞进答案，监督者只在旁边观察、不碰文件。

04

磁盘与数据库

应用数据与工作区状态分开存放：工作区可以切换， .data 跟着工作区走，于是同一份配置能开多个互不干扰的项目。

<app data>/

应用自己的文件，与工作区无关

config.json          # 30 个配置字段：模型 / 主题 / 工作区 / 守卫阈值
mcp_servers.json    # 用户面板维护的 MCP 花名册
sub_agents.json     # 子智能体清单
profiles.json       # 档案：配置 + 技能启用状态
agents/             # llm 型 agent 的 markdown 定义 + index.yaml
shadow/             # 每个窗口一份 config fork
workspace/          # 默认工作区
app.log             # 日志，按 log_retention_days 清理

<workspace>/.data/

随工作区走的隐藏状态，不自动创建的一律按需生成

chat.db              # history · session_meta · session_summaries
                       # api_requests · interaction_log · agent_missions
                       # agent_tasks · agent_bus_messages
memory/             # user/ · repo/ · evolution/（session 在内存）
todos/              # 任务清单
skills/             # 技能唯一根，每个技能一个 skill.md
skills.status       # 启用状态的唯一真源
scripts/            # run_cmd 脚本库（审批 + 预览）
mcp/ + mcp.conf     # 自建 MCP 服务器
tmp/<batch>/<task>/  # 子智能体交付物，永久保留
timers.json         # 未到点的 delay timer
05

关键约束

这些是读代码时最容易踩空的地方，也是这个架构真正的形状。

三个执行工具，三种边界

file_actions 只能在工区内（chat.db 例外）； run_cmd 只能跑一个 PATH 里的程序；run_shell 能到任意位置， 但先过语法闸门。

风险七级，处置不同

L0/L1 人工复核（≥90 强制拒绝）· L2/L3 警告 + 确认 · L4 放行 + 审计 · L5/L6 直接放行。确认可被 auto_accept_confirm_kinds 按类别放开。

一轮 = 多次请求

带 tool_calls 的 assistant 消息必须紧邻它的 tool 结果，所以注入只发生在 轮首；窗口已关的插话由前端丢掉并作为下一轮重发。

上下文四层压缩

结构化摘要（用量 0.8）· 工具台账（每轮 name(args)→结果）· 摘要接管 session_summaries · 预判 90% + 反应式重试；压缩失败自动退回机械摘要， 永远不会因此中断一次对话。

技能只有一个根

skill.md 所在目录即根，.. 一律拒绝。技能文件夹消失后 记录仍留在 skills.status，只是不再进模型。

交付物不清理

.data/tmp 永久保留，且刻意不进 profile 备份——它是交换区，不是状态。

单实例 + shadow 窗口

一个进程一个实例（instance.rs），每个窗口在 shadow/ 下拿一份配置 fork，互不覆盖。

自进化的护栏

维护轮可改 skills 与 memory，但 chat.db 与 skill.md 受保护：file_actions 只能读、只能写辅助文件， delete/rename/move 被拒绝。
